# SellerScout · 汽配新品观察

美国站 Automotive 难度 1 类目的静态选品工作台。打开 `index.html` 即可使用，也可通过 GitHub Pages 浏览。

## 当前快照

- 数据日期：2026-09-21。
- 范围：73 个低进入难度工作末级类目。
- 条件：售价 > $150、父体最新月销 1–9、ASIN 上架记录在近半年内。
- 每类最多 3 页，本次所有类目均在第 1 页完成筛选。
- 141 个父体候选；4 个错挂或超出普通配件范围的产品保留记录并移出优先池。
- 80 次官方 API 请求：73 次产品发现、7 次第四名查询（含缺失项的变体补查）。

第四名低于50只作参考，不作为淘汰门槛。多条销量时按最高值显示。候选展示具体规格、变体数量、品牌/自营情况及该条判断，保留完整英文标题。

## 使用

四个页签：候选产品、容易进入的类目、待进一步了解的类目、暂不优先的类目。

默认直接展示全部141个父体代表。后三页分别展示73、1542、335个已有分类；待进一步了解类目现已细分，并选8类试查；暂不优先组没有新增扫描。页面提供搜索、产品筛选和折叠使用说明。

“小类第四名”有多条销量时取最高值，商品链接对应这一最高值记录；未知值不当作0。

本仓库包含公开展示所需的 HTML、CSS、JavaScript 和筛选结果快照。数据直接内嵌在 HTML 中，无需构建、登录或后端；无 API 密钥、原始请求日志、本机路径或聊天记录。产品图片来自原始 Amazon 图片链接，链接可能失效。

销量来自 SellerSprite 估算；上架日期为展示 ASIN 记录，不代表父体首次上市。该表用于发现研究对象，不代表利润测算或可售性结论。

## 类目判断口径

按类目名称与通用产品知识初筛，综合进入要求、生产结构、适配安装与故障/售后责任。容易进入为明确挑选的73类；待进一步了解的1542类主要是默认归类，尚未逐项评估；暂不优先的335类主要按化学用品、燃油燃气、安全相关等分支归类。不是平台评级或已核实的资质结论。售价与销量不参与这三档分类。

不再根据标题中的年份自动生成适配年款建议；原始标题和上架记录日期仍保留。

## 待判断类目细分

原1542类分为：21类优先研究、76类先核对车型安装、507类先确认供应商能力、508类需要电气技术经验、243类需要承重固定验证、142类暂缓、22类范围外、23类信息不足。明确挑选21类，其余按产品分支初筛，不等于逐商品评估。第三页签可按方向筛选并展开8类的真实试查结果：共102个父体初筛命中，10次API请求。用途不符样本已标记。
